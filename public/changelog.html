Phase 1 — Foundation

Day 1 · v1.0
The core generator was already ambitious
Launched with channel selection (PN, WA, Email, In-App), product lines, drip journey builder, phone mockup preview, PN framework picker (PAS, BAB, Curiosity Gap, FOMO…), and a basic feedback loop. The bones were solid from the start.

Feature
Structured brief fields
Added User description, Desired action, Non-negotiables, and Reference material — so writers give the AI exactly what it needs upfront.
Feature
Tone dial + char counter
Writers can nudge outputs warmer or more direct. Char counter on WhatsApp variants flags the 160-char threshold in amber.
Feature
Per-variant regenerate
Regenerate a single variant without re-running the whole batch — faster iteration, less waste.
Feature
Editable drip journey length
Writers control the number of touches in a drip sequence, not just the cadence.
Phase 2 — Intelligence Layer
8–9 Jun
Feature
Five-layer intelligence stack
ToV rules · Word rules · Feedback examples · Learned insights · Procedural rules from edit memory — all five fire together on every generation. The more the team uses it, the more signal accumulates. Learning is global: one writer's feedback improves outputs for everyone.
Feature
Auto ToV rule extraction
Upload a ToV doc and the tool extracts structured rules automatically — no manual curation needed. Rules are injected into every prompt.
Feature
Word rules engine
Upload banned words and preferred replacements. Enforced in two places: the prompt (probabilistic) and a post-process filter (deterministic — 100% reliable).
Phase 3 — Auth + Visibility
9–10 Jun
Feature
Usage analytics dashboard
Tracks generations, daily trend, channel breakdown, product breakdown, tone dial and comm type usage. Writer-only access gated via Google OAuth.
Feature
Admin login
Separate username/password login for analytics access — no Google OAuth dependency. SHA-256 token stored as httpOnly cookie.
Feature
Google OAuth sign-in
Restricted to approved @acko.tech emails. Non-writers still get the generator; writers get the Analytics button in their profile.
Infra
Turso (cloud SQLite)
Migrated from local SQLite to Turso — persistent storage across Vercel deployments, readable from any device, no data loss on redeploys.
Phase 4 — Writer UX
10 Jun
Feature
Copy history
Every generated copy saved per writer. Browsable by date group (Today / Yesterday / This week) with channel and LoB filter pills.
Feature
Writer profile panel
Avatar dropdown with name, email, History link, Analytics link (writers only), and sign out. Clean and always accessible from the top-right.
UX
Generate more → direct pills
Replaced the clunky number-picker + button with three self-contained pills: +1, +2, +3. One tap, instant generation, no stale state bugs.
Fix
Push copy formatting
Push variants now render correctly everywhere — headline bold at top, body grey below. History, cards, and Word export all consistent.
Fix
Word export cleanup
Removed CRM scores and character counts from the exported .docx — just clean copy, ready to paste or share.
UX
Refine with AI — discoverability
Soft purple border + breathing glow animation on the refine bar. Sparkle icon nudges every 4s. Hard to miss now.
Fix
Framework enforcement
Selected PN frameworks (PAS, BAB, FOMO…) now enforced as a hard requirement in the generation checklist, not just as buried guidance.
Feature
Interactive team deck
10-slide keyboard-navigable HTML presentation at /deck.html — for sharing the tool with the team and stakeholders.
